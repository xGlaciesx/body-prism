# 省赛材料叙事与评审疑问

> 按第九届 AI WEB 省赛**以材料评审为主**准备，不预设现场答辩：视频和书面材料应独立讲清作品、实际 AI 链路和局限，不依赖评委追问。以下问答是制作材料时的自查，不是假设会有答辩。视频见 `DEMO-VIDEO-SCRIPT.md`。赛事具体提交细则以官方原文为准；视频按本次要求制作 5–8 分钟、1080p MP4。

## 一、核心叙事

人体棱镜是身体知识科普网页，尝试把器官、关系、来源和限制放在一起，便于读者继续核对。三镜是结构、关系、信息三种读法；传统理论应标明其语境，信息论是概念类比，不等同现代医学事实。作品不是诊断系统，不证明医学结论正确，也没有临床验证或效果对照实验。

材料优先展示一条真实使用路径：三维入口 → 器官内容 → 影响链边的机制、证据标识、来源和限定条件 → 提问及返回路径 → 局限。不要声称每句生成文本都可追溯或所有资料都已审核。

## 二、代码核验的 AI 链路

1. 影响链提问框把选中器官和问题发送到服务端 `/api/curator`；先检查请求和器官，再以固定关键词匹配急症红旗，命中时返回就医提示，不调用模型。词表不完整，不能替代分诊。
2. 普通问题经过进程内限流和缓存；缓存命中可直接复用。未配置密钥或模型调用失败时使用兜底。否则程序取当前器官的一阶子图，把边、机制、证据标识和来源 ID 放入提示词，与问题一起发给 DeepSeek 兼容接口；这是结构化上下文拼接，**不是**已实现的向量检索 RAG、Agent 或多轮自主推理。
3. 模型返回 JSON；服务端校验结构、回答长度、1–3 条有向边是否首尾相接且属于子图，以及非空来源 ID 是否在路径边的来源并集中。失败进入兜底。提示词要求每句对应边，但代码不验证这一语义关系，也不验证每条边都有各自引用，更不判定来源或医学内容真假。
4. 通过后前端显示回答并高亮返回路径；提问框不直接展示返回的来源 ID，需点图中边查看页面提供的来源。高亮是模型返回的结构，不是模型内部推理过程的证明。
5. 兜底按关键词选预置答案，未命中则给通用引导；路径和来源则取当前子图第一条边，**可能与兜底答案无关**，不能把高亮当作兜底答案的证据。浏览器与服务端通信失败或接口限流时，页面可能显示错误，而非兜底；不可承诺断网仍可提问。

依据：`src/app/api/curator/route.ts`、`src/components/curator-box.tsx`、`src/lib/curator-fallback.ts`、`src/content/impact-graph.ts`。密钥不出现在视频、截图或材料中；不要用真实个人健康信息演示。

## 三、评审可能关心的问题：材料自查

1. **解决什么问题？** 帮读者以结构化关系查看部分身体科普内容及其来源、限定条件，不解决个体诊断。
2. **有什么可操作的作品？** 展示可用的三维器官入口、三镜内容、影响链点击和提问，而非只展示 PPT。操作以实际页面为准。
3. **AI 具体做什么？** 根据器官一阶子图与用户问题生成文本、路径和来源 ID；后端检查结构与成员关系。它不是只负责润色，也不是医学判真器。
4. **为什么不直接问通用模型？** 作品尝试提供可点击的关系及来源以供核对，但没有比较实验，不能宣称更准确或更少幻觉；通用模型也可能提供来源。
5. **能否保证不胡说？** 不能。路径合法、来源 ID 合法也可能与回答语义不符；提示词不能保证不输出诊断或图外内容，来源本身也可能有误。
6. **红旗覆盖了所有急症吗？** 不能。只是有限的本地关键词匹配，不理解全部表达，也不承担分诊职责。
7. **模型不可用怎么办？** 无密钥、调用失败、超时或校验失败时服务端尝试兜底，关键词答案或默认引导与第一条边可能不对应；网络及限流错误另有页面错误提示。演示时如实标识模式。
8. **来源是否逐句显示？** 否。AI 提问区显示文本和模式，路径高亮；来源要在边详情中查看。来源 ID 检查不代表来源支持每句回答。
9. **图谱多大？** 当前代码包含 11 个器官、44 个节点和 56 条边；这是有限切片，不是完整知识库。提交时重新核对实际版本。
10. **证据 A/B/C/D 是什么？** 项目自定义标识：A 教科书级事实、B 综述或队列、C 传统理论、D 概念类比；并非完整 GRADE 流程，C/D 不可视作现代医学疗效证据，标记本身不能证明正确。
11. **谁完成了医学审核？** `medical-review-impact-graph.md` 有结构检查和逐边初审记录，同时明确最终结论需逐条签字；不能宣称完成逐条医学终审、专业医生审核或同行评议。需要合适专业人士复核。
12. **传统理论是否被现代医学证明？** 不作此声称；传统概念不能直接等同解剖结构，任何疗效或机制均需独立证据。
13. **信息之镜是否医学模型？** 不是，只是概念类比，不用于预测或个人健康判断。
14. **三维模型是否原创？** 不是；采用基于 Z-Anatomy 整理的素材，几何源自 BodyParts3D，许可见 `ATTRIBUTION.md`。展示位置和内容入口，不声称诊断、剖切或病理展示。
15. **系统筛选意味着器官模型分层吗？** 不意味着；筛选作用于热点，展示时以实际界面为准。
16. **没有数据库和登录是否只是静态页面？** 内容由版本化文件提供，交互和服务端模型接口并非纯静态；数据库不是判断作品价值的唯一标准。
17. **AI 在开发中参与多少？** 以实际可核实的提交记录和 `aigc-log.md` 为准，不编造比例或声称每次交互均有记录。
18. **有真实 AI 调用的证据吗？** 录制成功时保留实际页面及可安全展示的模式信息；避免重复问题的缓存混淆。未成功就说明未成功，不把兜底剪成 AI 回答。
19. **后续优先改什么？** 先完成专业医学复核、修正页面夸大描述，再评估语义一致性、兜底路径关联及红旗覆盖，补充可复现测试；这都是待做事项。
20. **最重要的限制是什么？** 知识覆盖有限、医学终审未完成、模型文本未做语义验证；图谱或免责声明都不能消除医疗误用风险。
