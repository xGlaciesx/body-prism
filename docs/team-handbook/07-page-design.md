# 页面设计方案（PRD + 线框 + 设计系统）

> 项目：人体棱镜 Body Prism——AI 驱动的身体信息三镜图谱。
> 目标：让 18–30 岁对健康好奇的年轻人，在 30 秒内看懂“这个网站不一样”，在 3 分钟内完成一次有证据的身体探索。
> 适用：两个大一新生，第一次做完整 Web 项目；先照此做 MVP，不要一次做完。

---

## 0. 先给结论

### 0.1 一句话体验

> **打开一具身体，切换三种读法，每次都告诉你“证据在哪”。**

### 0.2 页面清单

| 优先级 | 页面 | 路由 | 作用 |
|---|---|---|---|
| P0 | 首页 | `/` | 30 秒建立“三镜”心智，导流到身体地图 |
| P0 | 身体地图 | `/explore` | 3D 身体 + 器官热点 + 三种读法入口 |
| P0 | 器官详情 | `/organ/[slug]` | 核心学习页：三镜卡片 + 证据 + AI 追问 |
| P1 | 信息负荷实验室 | `/lab/info-load` | 用可交互模拟讲“信息噪声”，比赛记忆点 |
| P1 | 争议地图 | `/controversies` | 展示共识/不确定/争议，建立可信度 |
| P1 | 方法与证据 | `/method` | 证据等级、AI 边界、中医与信息论声明 |
| P2 | 关于 | `/about` | 团队、署名、AIGC 披露、仓库 |
| P1 | 管理后台 | `/admin/*` | 客户只读、管理员管理内容；见文档 06 |

### 0.3 设计关键词

```text
自然史博物馆的展签
+ 现代科学图谱的克制
+ 纸张与墨水的质感
+ 一层一层揭开，而不是一次性倒完
```

### 0.4 不做什么

- 不做“包治百病”的健康门户；
- 不做症状自查/诊断问卷；
- 不做信息流、评论区、用户投稿；
- 不做炫技到看不清身体的 3D；
- 不做每页都弹 AI 聊天框；
- 不在首屏堆满 20 个功能入口。

## 1. 业界参考：借什么，不借什么

| 参考 | 它做得好的地方 | 我们借什么 | 不借什么 |
|---|---|---|---|
| **Apple Human Interface Guidelines** | 清晰、克制、内容优先 | 大图、少装饰、明确层级、动效服务于理解 | 苹果式极简到没有信息 |
| **DK 百科 / Britannica** | 图文关系、展签式说明 | “一图 + 一段 + 一个小知识”的节奏 | 纸书式密集排版 |
| **Google Arts & Culture** | 可缩放作品 + 热点 | 3D/大图上的热点、局部放大 | 过度沉浸导致迷路 |
| **MoMA / 博物馆语音导览** | 编号展品、短段落、可跳听 | “展签 + 编号 + 继续看”的叙事 | 线性强制游览 |
| **NIH Visible Human / BodyParts3D** | 解剖分层、结构 ID | 分层、隔离、结构命名与署名 | 直接把科研工具界面搬给大众 |
| **The Pudding / Observable** | 滚动叙事 + 可操作图表 | 信息负荷实验室的滑杆与即时反馈 | 复杂到需要教程 |
| **Stripe Docs** | 信息架构、搜索、代码块 | 清晰的侧栏、搜索、可复制内容 | 开发者文档的密度 |
| **Linear** | 快速、键盘友好、状态清楚 | 命令面板、快捷键、加载态 | 深色 SaaS 风 |
| **Mayo Clinic / Healthline** | 通俗语言、医学审核、红旗提示 | 一句话总结、误区、就医边界 | 广告式健康内容 |
| **NN/g + WCAG 2.2 AA** | 可用性与无障碍 | 识别优于回忆、键盘可达、对比度 | 只做“看起来酷”的交互 |

**结论：**

> 用博物馆的“展签”组织内容，用科学图谱的“证据”建立信任，用 Apple 的“克制”控制界面。


- 加载：骨架屏，不用全屏转圈；
- 空状态：一句人话 + 一个下一步按钮；
- 错误：说明“哪一块坏了”，给“重试”和“返回地图”；
- 3D 不支持：自动切 2.5D 图谱，不显示“你的浏览器不支持”就结束；
- 网络慢：先出文字和静态图，3D 后到。

## 4. 设计系统

### 4.1 视觉方向

```text
纸：暖白、米色、轻微纹理
墨：近黑，不用纯黑
光：三种镜片各有一个强调色
线：细线、编号、展签
动：慢、短、可关闭
```

### 4.2 色彩

```css
:root {
  --paper: #f7f2e8;
  --paper-2: #fffdf8;
  --ink: #1c1a17;
  --muted: #6f675c;
  --line: #ded4c5;

  --rose: #a6474f;      /* 结构之镜 */
  --ochre: #c98a3e;     /* 关系之镜 */
  --cyan: #2f8f9d;      /* 信息之镜 */
  --sage: #6f7f6a;      /* 证据/通过 */

  --danger: #b03a2e;
  --focus: #2f8f9d;
}
```

| 用途 | 颜色 | 说明 |
|---|---|---|
| 页面背景 | `--paper` | 暖白，不刺眼 |
| 卡片 | `--paper-2` | 比背景亮一点 |
| 正文 | `--ink` | 对比度 ≥ 7:1 |
| 次要文字 | `--muted` | 对比度 ≥ 4.5:1 |
| 结构之镜 | `--rose` | 解剖、位置、层次 |
| 关系之镜 | `--ochre` | 经络、筋膜、轴 |
| 信息之镜 | `--cyan` | 信号、网络、带宽 |
| 证据通过 | `--sage` | A/B 级证据 |

规则：

- 颜色永远不单独承载信息，必须配文字/图标；
- 三种镜片的颜色只做强调，不做大面积背景；
- 红色只用于红旗/危险，不用于装饰。

### 4.3 字体

| 层级 | 字体 | 用途 |
|---|---|---|
| Display | `"Noto Serif SC", "Source Han Serif SC", serif` | 大标题、器官名、展签标题 |
| UI | `"Inter", "Noto Sans SC", sans-serif` | 导航、按钮、正文 |
| Mono | `"JetBrains Mono", ui-monospace` | 数据、公式、来源编号 |

字号阶梯：

```text
12 / 14 / 16 / 18 / 22 / 28 / 36 / 48 / 64
```

- 正文 16–18px，行高 1.7；
- 长文最大宽度 68ch；
- 数字用 `font-variant-numeric: tabular-nums`；
- 中文标题不要用超粗字重，600–700 足够。

### 4.4 间距与形状

```text
间距：4 / 8 / 12 / 16 / 24 / 32 / 48 / 64 / 96
圆角：4（标签）/ 8（按钮）/ 12（卡片）/ 16（大面板）/ 999（胶囊）
边框：1px solid var(--line)
阴影：0 12px 30px rgba(28,26,23,.07)，只给浮层
```

### 4.5 3D 视觉规范

- 材质：哑光、纸黏土感，`roughness 0.8–0.9`，`metalness 0`；
- 颜色：器官用低饱和的红/赭/青，不做游戏高光；
- 灯光：暖色主光 + 冷色轮廓光 + 柔和环境光；
- 背景：与页面同色，不加星空/渐变；
- 相机：35–50mm 等效，透视 35°；
- 动效：默认缓慢自转，用户操作后停止；
- 标注：HTML 热点，不用 3D 文字贴图；
- 性能：Draco + KTX2，首包 3–5MB，桌面 60fps，移动 30fps。

### 4.6 图标与插画

- 图标：1.5px 线性，圆角端点；
- 插画：19 世纪自然史图谱风，墨线 + 淡水彩；
- 信息图：代码/SVG 生成，不用 AI 生成带文字的图；
- 所有解剖图必须能对应到 3D 结构 ID 或来源。

### 4.7 动效

| 场景 | 时长 | 说明 |
|---|---|---|
| 镜头移动 | 600–900ms | `easeInOutCubic`，可跳过 |
| 卡片进入 | 200–300ms | 轻微上移 + 淡入 |
| 热点脉冲 | 2s 循环 | 只给未选中器官，低幅度 |
| 抽屉 | 250ms | 右侧滑入 |
| 数字变化 | 300ms | 滑杆联动，不做弹跳 |

必须支持 `prefers-reduced-motion`：关闭自转、脉冲、滚动动画。

### 4.8 可访问性

- 对比度：正文 ≥ 7:1，次要文字 ≥ 4.5:1；
- 键盘：Tab 可达所有热点/滑杆/按钮，焦点环 2px；
- 3D 画布提供“文字版身体地图”切换；
- 所有图片有 alt；装饰图 `alt=""`；
- 视频/动画有暂停；
- 颜色 + 文字双编码；
- 表单错误用文字说明，不只变红；
- 目标：WCAG 2.2 AA。

### 4.9 响应式

| 断点 | 布局 |
|---|---|
| `< 640px` | 单列；3D 全屏 + 底部抽屉；导航折叠 |
| `640–1024px` | 两列；侧栏变顶部横向 chips |
| `> 1024px` | 三列；左导航 + 中 3D + 右详情 |
| `> 1440px` | 内容最大 1280px，居中，不无限拉宽 |

## 5. 页面级设计

### 5.1 首页 `/`

#### 目标

30 秒内回答三个问题：

1. 这是什么？——一具可以切换三种读法的身体。
2. 为什么可信？——每个说法有证据等级和来源。
3. 我接下来做什么？——进入身体地图，或从心脏开始。

#### 首屏线框

```text
┌──────────────────────────────────────────────────────────────────┐
│ Header                                                           │
├──────────────────────────────────────────────────────────────────┤
│                                                                  │
│  AI 驱动的身体信息三镜图谱                                         │
│                                                                  │
│  同一具身体，                                                      │
│  三种读法。                          ┌──────────────────────┐    │
│                                      │                      │    │
│  结构之镜看它如何构成，               │      3D 人体         │    │
│  关系之镜看它如何联结，               │      缓慢自转         │    │
│  信息之镜看它如何传递。               │      器官热点         │    │
│                                      │                      │    │
│  [ 进入身体地图 ]  [ 让策展人带你看 ]  └──────────────────────┘    │
│                                                                  │
│  ↓ 从一颗心脏开始                                                 │
└──────────────────────────────────────────────────────────────────┘
```

#### 首屏以下

1. **一面棱镜，三种光**：三张横卡，分别解释结构/关系/信息，各配一个 3 秒微动效。
2. **从一颗心脏开始**：左侧 3D 心脏，右侧三条“你会看到什么”，按钮“打开心脏展签”。
3. **你的注意力，带宽够用吗？**：一个滑杆 + 一个“有效处理带宽”仪表，按钮“进入实验室”。
4. **我们如何保证可信**：A/B/C/D 证据徽章 + “读方法”链接。
5. **边界声明**：不是诊断工具；急症请就医。

#### 交互

- 首屏 3D 只做缓慢自转 + 6 个热点；不做滚动绑定的大动画，避免手机卡顿。
- 点击热点直接进入对应器官页。
- “让策展人带你看”打开一个 3 步导览：心 → 脑 → 肠，每步一个镜头 + 一句话。
- 所有动画可跳过。

#### 验收

- [ ] 首屏 3 秒内出现标题和 CTA，不依赖 3D
- [ ] 3D 加载失败仍有静态人体图和入口
- [ ] 手机首屏不横向滚动
- [ ] 减少动效模式下无自转/脉冲
- [ ] CTA 都能到达正确页面

#### 左栏

- 系统筛选：8 个系统，MVP 只做与六器官相关的 6–8 个；
- 器官列表：6 个，带小圆点/颜色；
- 选中态明显，键盘上下可切换；
- “全部”恢复完整身体。

#### 中间 3D

- 默认半透明皮肤/轮廓，器官可见；
- 悬停：高亮 + 名称标签；
- 点击：选中 + 相机聚焦 + 右栏更新；
- 工具栏：
  - 重置视角；
  - 隔离（只显示选中器官）；
  - 淡出其他（fade）；
  - 全屏；
  - 画质（自动/高/低）。
- 不支持 WebGL：切 2.5D 分层图谱，热点仍可点。

#### 右栏

- 器官中英文名、系统；
- 一句话总结（≤ 40 字）；
- 三镜 chips，点击直接跳到详情页对应锚点；
- “打开展签”主按钮；
- 证据数量、来源数量；
- 相关器官 2–3 个。

#### 移动端

```text
┌──────────────────────┐
│ Header               │
├──────────────────────┤
│                      │
│      3D 全屏          │
│      热点可点         │
│                      │
├──────────────────────┤
│ 心 脑 肺 肠 肾 筋膜   │  ← 横向 chips
├──────────────────────┤
│ 底部抽屉：心脏简介     │
│ [打开展签]            │
└──────────────────────┘
```

#### 状态

- 加载：3D 骨架 + “正在准备身体模型”；
- 空搜索： “没有找到这个结构，试试心/脑/肺”；
- 错误： “模型加载失败，切换到图谱模式”；
- 低性能：自动降低 DPR、关闭阴影、减少结构。

#### 验收

- [ ] 6 个器官热点都能点中
- [ ] 键盘能切换器官
- [ ] 隔离/重置/全屏可用
- [ ] 手机底部抽屉不遮挡热点
- [ ] 2.5D fallback 可用
- [ ] 首次 3D 资源 < 5MB

### 5.6 方法与证据 `/method`

#### 内容

1. 证据等级 A/B/C/D 的定义；
2. 我们如何选来源（指南、系统综述、RCT、教科书、专家意见）；

8. 3D 数据署名；
9. 更新日志；
10. 联系方式。

#### 证据等级表

| 等级 | 含义 | 例子 |
|---|---|---|
| A | 指南/系统综述/高质量 RCT | 高血压指南、Cochrane 综述 |
| B | 单项 RCT/队列/权威教科书 | 单中心试验、教科书章节 |

| D | 传统理论/个案/待验证 | 中医经典理论、初步假说 |

> D 不是“错”，是“证据强度低”；页面上必须写清楚。

## 7. 内容与文案规范

### 7.1 每个器官的固定结构

```text
1 句话总结（≤ 40 字）
3 张镜片卡（结构 / 关系 / 信息）
1 个常见误区
3 条来源（至少 1 条 A/B）
3 个 AI 追问
1 个 3D 相机预设
```

### 7.2 镜片卡写法

```text
标题：4–8 字
正文：2–3 句，≤ 120 字
证据：A/B/C/D
来源：[S1][S2]
```

### 7.3 中医内容

- 必须标“传统理论”；
- 必须区分“经典描述”与“现代研究”；
- 不把经络写成解剖结构；
- 有争议就并列呈现；
- 不用“西医不如中医”这类对立文案。

### 7.4 信息论内容

- 必须标“概念类比”；
- 公式只在实验室/方法页出现；
- 不把香农定理说成“测量大脑带宽”；
- 引用效率编码、预测加工、网络生理学时要标证据等级。

### 7.5 心脏页文案示例

```text
一句话：
心脏是一台有节律的泵，也是一套会向全身发送信号的器官。

结构之镜：
四个腔室、四组瓣膜，按顺序开合，把血液送往肺和全身。
证据：A · [S1]

关系之镜：
中医把心看作“主血脉、藏神明”，这是传统理论；
现代医学看到的是心—脑—肾—肺之间的协同。
证据：B/C · [S2][S3]

信息之镜：
压力感受器、交感/副交感神经和激素，把血压和血量
变成持续更新的信号。心脏不只是被命令，它也在发信号。
证据：B · [S4]

常见误区：
“心跳越快越健康” —— 静息心率因人而异，持续过快需要就医评估，
不能用一个数字判断健康。
```

## 9. AI 交互设计

### 9.1 角色

**棱镜策展人**，不是“医生”，不是“聊天机器人”。

语气：

- 像博物馆讲解员：先给一句话，再展开；
- 不卖焦虑，不用“你必须”；
- 不确定就说不确定；
- 不诊断、不开药、不给剂量。

### 9.2 回答结构

```text
一句话：……
结构之镜：…… [S1]
关系之镜：…… [S2]
信息之镜：…… [S3]
证据等级：B
你可以继续问：……
```

### 9.3 状态

| 状态 | 界面 |
|---|---|
| 空闲 | 3 个建议问题 |
| 流式生成 | 逐段出现，显示“正在查证据” |
| 有引用 | `[S1]` 可点击，右侧来源高亮 |
| 无来源 | “知识库暂无可靠来源”，不硬编 |
| 红旗 | 停止生成，显示急症就医提示 |
| 超时 | 重试 + 推荐相关展签 |
| 限流 | “今天问得有点多，明天再来” |

### 9.4 比赛展示

- 打开“查看策展过程”；
- 显示：意图解析 → 器官定位 → 三镜检索 → 证据审计 → 生成展签；
- 每一步有耗时/工具名/命中来源数；
- 这是 AI 技术分的现场证据。
