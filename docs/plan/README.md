## 这一包怎么组织

编号是门牌号，不是阅读顺序。四个字母代表四类东西：

| 系列 | 含义 | 编号 | 给谁 |
|---|---|---|---|
| **D** | 资料：环境、Git、页面设计、素材许可、三维方案 | D00–D17（18 份） | 孩子查漏时翻 |
| **P** | 计划与说明：执行计划、给老师的说明、给家长的说明 | P0–P10（11 份） | 孩子执行 / 老师把关 / 家长代发 |
| **S** | 提交材料：交给比赛方的东西 | S1–S5（5 份） | 比赛方 |
| **T** | 任务卡，收在 P2 里 | T0–T14（15 张） | 孩子每天一张 |
| **M** | 文档地图 | M0（1 份） | 孩子查编号 |

**所有交叉引用统一写成「编号 §章节」**，例如 `D17 §2.4`、`P2 · T14`。写不成这个格式的地方就是错了。

## 给孩子的使用方式

- **先读 HTML 版**，排版更适合直接看；要复制配置或提示词时再打开对应的 Markdown；
- **李若溪用 Windows 11 + PowerShell，张子昂用 macOS + Terminal**，文档里标了系统的命令，不要混抄；Windows PowerShell 5.1 不支持 `&&`，两条命令分两行；
- **只照 P2 执行**，D04 和 D16 是旧排期，看到"已被取代"的提示就跳过；
- 卡住时先翻 P2 §8 的排错表，再按表里的编号链接翻对应文档；
- 每份文档里的文件路径，都是建议放在项目根目录下的位置；
- **所有 API Key 只放本地 `.env.local`，永远不进仓库。**
