# 人体棱镜 · 每天照这个点

> 打印 A4 一张，贴在两台电脑中间。卡住查 P8 §7，别在墙上找答案。

## 一、早上 3 分钟

1. 群里发：「**D? · 我做 T?**」
2. 左下角点分支名 → `main` → 点 **⟳ 同步**
3. 再点分支名 → **Create new branch** → `feat/d?-名字`
4. 打开 `docs/PLAN-DAILY.md`，**只看今天那一格**

## 二、白天：一次只给它一件事

今天那格的代码块**整块**粘给 Cline，回车。**它做完就停**——所有翻车都来自"顺便把别的也改一下"。

## 三、晚上 10 分钟

1. 贴给 AI：

   ```text
   依次跑 npm run lint、npm run test、npm run build，三条都跑完再一起告诉我结果。
   失败的那条把报错原文贴出来，不要自己改代码。
   ```

2. **三条都绿才算完成**；有一条红，别提交
3. 「源代码管理」→ 写 `feat(...)` → **✓ Commit** → **Sync Changes**
4. GitHub → **Create pull request** → 对方 **Approve** → **Squash and merge** → **删分支**

## 四、三句口令（直接抄）

| 什么时候 | 说什么 |
|---|---|
| **开始干活** | 把今天那格的代码块整块粘贴，回车 |
| **它说完成了** | 「你说完成了。跑一遍 `npm run build`，把最后几行输出原样贴出来，不要总结。」 |
| **收工** | 贴 P8 §4.4 那一整段「同步计划」提示词，只改「今天的情况」那一行 |

## 五、六条铁律

1. **一次只让 AI 做一件事**
2. **它说"完成"不算**——命令绿了、页面对了才算
3. **同一问题试三次还不行** → 停下来问人
4. **分支不过夜**——当天开的 PR 当天合
5. **绝不** `git push --force`、`git reset --hard`
6. **绝不**把冲突攒到 D7 再合

## 六、卡住先问四句

报错原文**贴全**了吗？　·　VSCode 打开的是 `body-prism` 吗？　·　F12 → Console 看了吗？　·　`.env.local` 改完**重启**了吗？
