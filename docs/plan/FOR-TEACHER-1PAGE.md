# 给老师的一页说明

**张玉龙老师，您好：**

我们是西安交通大学的大一新生，李若溪（电子信息工程）、张子昂（临床医学），队名「昂昂若驹」，想参加第九届传智杯 AI WEB 挑战赛。这份是一页纸的简版，详细的说明附在后面。

## 我们为什么想参加

大一课程还在打基础，但有两件事我们觉得不能等。一是把 AI 真正用在一个必须交付的东西上，而不是停留在概念；二是把网页从写页面到部署上线这条路完整走一遍。我们俩专业不同，正好可以拿"人体"做一个两边都能插手的题目，也顺便攒一次完整的比赛经验。

## 项目是什么

做一个网站，把「某个器官影响哪些功能、这些功能出问题可能有什么表现」这条链画出来，每一步都能点开，看到机制、证据强度和出处。用西医、中医、信息论三种读法讲同一具身体，后两种会明确标注"传统理论"和"概念类比"，不当作医学结论。AI 只能沿我们标注好的关系图作答，走完必须交出路径，服务端逐条核对，对不上就作废。不做诊断，不涉及用药。

## 现在到哪了

11 个器官（心、脑、肺、肝、肾、胃 + 脾、胆、小肠、大肠、膀胱）的内容和证据分级已经做完，56 条器官与功能的关系已经写好，三维模型也合并好并验过了，仓库能跑、有自动检查，技术文档 24 页。还没做的是影响链页面、AI 接口、三维视图的接线和线上地址，计划一周内补齐。
